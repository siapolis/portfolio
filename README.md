# Anastasia Polishuk — Portfolio

Static portfolio site published with GitHub Pages: https://siapolis.github.io/portfolio/

## Structure

```
index.html        page markup
css/style.css     styles
js/main.js        translations (EN / SK / RU), contact links, video playback
assets/img/       images
assets/posters/   video poster frames
assets/video/     video clips (mp4, loaded when scrolled into view)
```

Contact details are set in the `CONTACT` object at the top of `js/main.js`.

## Run locally

```
python3 -m http.server 8000
```
Open http://localhost:8000
